# src

## Overview
Application source for the Bacha Rouge site, using the `@/*` import alias. Routing, layout and global styling live in `app`; reusable UI and animation live in `components`.

## Subdirectories & Boundaries
- app: [./app/CLAUDE.md](./app/CLAUDE.md) - App Router layout, fonts, metadata, design tokens, and the single `Home` page.
- components: [./components/CLAUDE.md](./components/CLAUDE.md) - sections, the GSAP motion wrapper, and shared UI primitives.
