# src

## Overview
Application source for the Bacha Rouge site, using the `@/*` import alias. Routing, layout and global styling live in `app`; reusable UI and animation live in `components`; contact details and the menu live in `content`; languages and home-page text live in `i18n`.

## Subdirectories & Boundaries
- app: [./app/CLAUDE.md](./app/CLAUDE.md) - App Router root layouts per language, fonts, design tokens and the home and menu pages.
- components: [./components/CLAUDE.md](./components/CLAUDE.md) - home sections, the GSAP motion wrapper, the menu page and shared UI primitives.
- content: [./content/CLAUDE.md](./content/CLAUDE.md) - `CONTACT` (address, numbers, Instagram, link helpers; shared by every language), the hand-copied Google reviews and the menu data.
- i18n: [./i18n/CLAUDE.md](./i18n/CLAUDE.md) - `LOCALES`, `localePath()`, hreflang helpers and the typed home-page dictionaries.
